# Security Policy

## Supported Versions

Only **v0.1.0** is currently supported for security fixes.

## Reporting a Vulnerability

To report a security vulnerability, use **Report a vulnerability** on the [Security Advisories page](https://github.com/wheesnoza/pest-plugin-pao-mutation/security/advisories). Reports are private. We will review the report and decide how to respond.

Use Issues for ordinary bugs. Do not post details of unpatched vulnerabilities or secrets in public Issues.
