# Pest Plugin PAO Mutation

Pest plugin scaffold for publishing the `pest --mutate` support proposed in [laravel/pao#43](https://github.com/laravel/pao/pull/43) as a separate package.

This repository currently contains only the [official Pest plugin template](https://github.com/pestphp/pest-plugin-template) adapted to this package. It does not yet integrate with PAO or format mutation results.

## Development

```bash
composer install
composer test
```
